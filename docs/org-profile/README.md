# 🧭 OpenPathfolio

**Free, open-source tools that help students and parents plan the path from high school to college.**

Choosing a career and a college is confusing, especially for families who are still exploring. OpenPathfolio brings it all into one place: career exploration, universities, internships and programs, and the certifications, projects and research that make a strong application.

### 🚀 [Pathfolio](https://github.com/openpathfolio/pathfolio)
| | |
|---|---|
| 🧭 Career quiz | Find career paths that match the student's interests, subjects and values |
| 🧰 Profile-building kits | Courses, certifications, projects, internships, competitions, research and where to publish, for 26 career paths |
| 📌 Opportunities | Internships, summer programs and competitions, refreshed weekly with human review |
| 🏫 Universities | Starting with Texas, with more states on the way. Reach, Target and Likely labels, costs and lower-cost pathways. |
| ✅ My Plan | Track everything from 9th grade to decision day |

**Try it:** https://openpathfolio.github.io/pathfolio/

### Our principles
- **Free for every family.** No ads, no paywalls, no sign-up.
- **Private by design.** Student data stays in the student's browser.
- **Honest guidance.** Official sources, free and paid-to-student programs first, and no pay-to-play.
- **Community-maintained.** Parents, students, counselors and developers keep it current.
